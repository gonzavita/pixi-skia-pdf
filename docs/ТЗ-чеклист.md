## 1. Реализация обёртки для Skia
- [x] TypeScript-обёртка (интерфейс) для Skia, принимает `PIXI.Container` — `PixiToSkiaRenderer`
- [x] Поддержка трансформаций: translate (сдвиг)
- [x] Поддержка трансформаций: rotate (поворот)
- [x] Поддержка трансформаций: scale (масштаб)
- [x] `PIXI.Graphics`: `drawShape`, `moveTo`, `lineTo`, `drawRect` (rect/circle/ellipse/rrect/polygon)
- [x] `PIXI.Sprite` (png-картинки)
- [x] Функция `convertPixiContainerToSkia(container: PIXI.Container)`

## 2. Экспорт в PDF
- [x] Экспорт сцены в PDF через Skia PDF backend — `pdfExport.ts`, `ck.MakePDFDocument`
- [x] Результат векторный — рендер Skia-путями прямо в PDF-страницу
- [x] CanvasKit с PDF backend — пакет `@rollerbird/canvaskit-wasm-pdf`
      (сборка CanvasKit с `skia_enable_pdf`; стандартный `canvaskit-wasm` PDF не содержит)

## 3. Интерактивность и события
- [x] События `pointerDown` и `pointerUp` для `PIXI.DisplayObject`
- [x] События работают на ОБОИХ канвасах (Pixi — нативно, Skia — хит-тест)
- [x] Кнопка «Сгенерировать случайную линию/фигуру»
